# 固定机器人状态的位移探针结果

已完成20个新场景（initial20..39），8种预声明位移：目标沿world X/Y分别±5/±10毫米。机器人状态和推理噪声固定。共160个候选分支，151个有效，9个因穿插排除；训练91、验证29、测试31样本，按场景隔离。

验证集选中prefix0（零基索引），测试每坐标RMSE4.388毫米；常数/恒零状态差对照5.531毫米；图像RGB均值变化对照2.416毫米。激活不是最强的读出来源。这里方向正确率80.6%仅指预测与真实位移点积为正，不等于精确角度正确。动作专家池化激活未稳定优于常数对照。

## 可以和不可以得出的结论

- 已排除同一场景内机器人状态变化这一直接干扰。
- 视觉语言池化激活存在可读出的位移相关信息，但简单图像统计更好，不能称为语义特征发现。
- 动作专家读出弱，可能来自池化丢失token/时间结构、小样本、量化/非线性等，不证明模型没有使用目标位置信息。
- 全部为观测级位移，没有执行闭环动作，不能据此报告纠正成功率。

## 下一步

先保留视觉token的空间布局和动作token的时间位置，再用相同协议比较读出；选择仅按验证集，最终使用新的初始场景评估。加入同幅度非目标物体位移，检查读出是否只反映一般图像变化。通过后才做针对特征的闭环干预，不直接训练SAE或宣称反馈回路。
