# v3空间与非目标位移读出结果

26场景，目标及非目标黑碗各8种位移；有效396分支，无效20分支。训练/验证/测试按场景隔离：{'train': 91, 'validation': 29, 'test': 73}（此处只统计目标样本），测试初始状态40..49为新场景。

验证集选出的激活：`prefix_17_grid4`。测试目标位移坐标RMSE 3.708毫米，常数对照 5.504毫米。同一个探针在双方有效的72组位移中，目标位移读出平均范数 5.891毫米，非目标位移读出平均范数 2.446毫米。

这些数值是读出能力和特定对照下的响应差异，不是闭环任务成功率，也不证明语义绑定、反馈机制或修复。另一只黑碗位于不同空间位置，差异可能来自空间位置或可见性。v2与v3使用不同测试场景，不能直接将误差差值解释为空间池化的改进。完整候选与简单图像均值对照见 `RESULTS.md`。

下一步依据结果决定：若空间读出仍弱，先检查token定位与数据；若读出可靠，再用同一物体切换语言目标等对照排除位置捷径，并验证特征干预的闭环行为。尚不开始SAE训练。
