# CoRL 2027 唯一推荐方向：VLA 的因果反馈通路识别与修复

**Seeing the Change, Missing the Correction: Identifying and Repairing Feedback Pathways in Vision-Language-Action Policies**

选题日期：2026-10-22。资源假设：可使用你的 RTX 5090 服务器。

**本方案取代此前“目标表示重绑定／因果交换训练”方案。此前方案不再作为推荐主线。**

## 1. 我现在建议研究什么

研究一个具体的机器人机制问题：

> 目标物体发生位移后，VLA 已经重新读取最新图像，内部表示也包含了位置变化，但动作为什么仍然不能正确纠偏？能否定位并修复将感知更新转化为纠偏动作的少量内部计算，使策略恢复跨任务的反馈控制能力？

把这一问题称为**反馈通路失效**。这个名称描述的是待检验的机制，不是已经证明所有 VLA 都存在的现象。

推荐的主线是：**受控物理扰动 → 因果定位反馈通路 → 定向修复 → 验证扰动后的闭环恢复。**

这次不把“SAE 加到 VLA 上”当创新，也不以更清晰的 latent 聚类作为目标。SAE 是识别内部计算的工具；研究对象是策略对物理变化的反馈响应。

我的判断：相较此前方案，这个方向的创新空间更明确，机器人贡献更直接，值得作为面向 CoRL 2027 的主线投入。这个判断基于下文对前作的对比；它不等于已证明现象存在，也不等于录用保证。

## 2. 用一个实验说明核心问题

机械臂正在伸向杯子。抓取前，杯子向右平移一小段距离。

必须先分清三类失败：

1. **新画面没有进入计算。** 旧动作块还在执行，或推理/通信延迟造成观测陈旧。这属于调度和反应速度问题。
2. **新画面进入计算，但位置变化没有被正确表示。** 这是感知或状态估计问题。
3. **位置变化已在内部表示中出现，但动作没有产生足够、方向正确的修正。** 这是本项目要定位的反馈通路问题。

第三类不能仅凭一个位置 probe 准确就成立。必须进一步通过内部干预说明：改变候选通路，确实会选择性地改变对物体位移的纠偏响应。

第一阶段在仿真中设置：每次执行一个动作前暂停物理推进、获取当前图像、清空旧动作队列并重新推理。这样不受真实推理耗时影响。若此时仍出现第三类失败，再研究模型内部。

后续部署实验恢复真实运行时间，单独测量延迟。这两个实验不能混写为“实时结果”。

## 3. 与前作真正不同在哪里

| 最近前作 | 它已经研究的内容 | 本项目的差异与必要证据 |
|---|---|---|
| SAE-VLA / DR.VLA [1] | 可解释特征、运动原语、特征通用性与 steering | 识别的是“物理扰动引起的纠偏响应”所依赖的通路；需要保留正常执行、选择性改变反馈的证据 |
| Not All Features Are Created Equal [2] | 坐标绑定的运动程序、VLM/专家通路差异、注入和位移实验 | 不再声称首次发现坐标记忆；研究新观测已到达时，反馈在哪个计算环节衰减，以及如何修复 |
| Event-Grounded SAE [3] | 行为事件关联与干预，揭示 SAE 干预的局限 | 事件共现之外，要测量有方向、有幅度的扰动—响应关系 |
| SOUL [4] | 根据失败/成功特征做选择性遗忘与保留 | 不按“失败时激活”删除特征；用受控扰动确定反馈作用，修复正确的响应关系 |
| CTRL-STEER [5] | PID/RL 在线调节 steering 强度，控制速度、平滑度等概念 | 研究基础策略自身的感知—纠偏通路；部署不依赖外部目标误差真值来调 steering |
| REACT / 动态推理 [6–7] | 更新观测、动作流和推理调度以提高反应性 | 固定观测新鲜度和执行频率后识别剩余的模型计算失效；还要验证与调度方法是否互补 |
| Spatial Attention [8] | 根据观测敏感度分配执行 horizon | 不以敏感度大为好；要求动作变化方向正确、大小适当，并定位其内部来源 |
| TaSIL [9] | 模仿专家的高阶局部响应，提高鲁棒性 | 导数/差分匹配本身不是创新；本项目贡献必须包括内部因果定位和选择性修复的额外价值 |
| Sensitivity Shaping for Latent Modeling [10] | 修复动力学模型对控制输入不敏感的问题 | 研究的是策略中“物理状态变化 → 动作纠正”，而非世界模型中“动作变化 → 预测状态变化” |

**本轮检索未发现上述工作已经完整完成“排除调度影响 → 因果分离名义执行与反馈响应 → 据此定向修复 → 跨任务闭环验证”的同一条证据链。** 这比“没有人用过某个模块”更有意义，但仍需持续跟踪新稿，不能写成无保留的首次声明。

## 4. 创新点应该落在哪三件事上

### 4.1 一个可证伪的机制发现

假设 H1：在一部分失败状态中，内部仍保留任务相关的位置变化信息，但这些变化对动作的有效影响减弱或方向错误。

假设 H2：存在一组内部计算，干预它们对正常无扰动轨迹影响较小，却显著改变扰动后的纠偏表现。

假设 H3：根据这种反馈作用定位修复位置，比按激活强度、失败相关性或随机位置选择更有效，并能迁移到未参与定位的任务。

这些是假设，不是待包装的结论。不是所有失败都属于 H1；如果主要原因是图像没有被正确编码，就不能硬归为反馈失联。

### 4.2 按“反馈作用”定义 latent

普通 SAE 分析常从“这个特征在什么画面/任务里激活”开始。本项目从不同问题开始：

> 移动物体或改变机器人状态时，哪些特征变化会导致正确的纠偏？哪些只是观察到了变化，却对纠偏不起作用？

特征至少区分三类：

- **感知变化特征**：能反映扰动，但未证实影响动作。
- **反馈有效特征**：受扰动影响，并经干预证实影响方向正确的纠偏。
- **名义执行特征**：主要支撑正常动作或阶段推进，干预后可能整体破坏任务。

这是一种按控制作用定义的 latent 研究。特征可由一组方向共同实现，不能强求“一维就是一个物理概念”。

### 4.3 基于机制的定向修复

修复目标不是增强所有敏感度，而是恢复任务相关变化到纠偏动作的映射，同时限制对无关外观变化的反应。

成功的修复应使机械臂对杯子左移和右移产生相反而适当的修正，对背景纹理变化保持稳定，并在无扰动任务上保留能力。

**最重要的额外价值：**在同一批纠偏数据、同等训练预算和参数量下，依据反馈因果定位选择的修复位置，比普通 LoRA、随机位置和仅用差分损失更有效。否则无法证明机制分析对方法有用。

## 5. 仿真实验如何做到因果上可信

### 5.1 从同一个快照分叉

在动作执行过程保存仿真状态，从同一快照建立分支：

- 无扰动分支；
- 目标物体沿某方向平移 +δ；
- 沿同方向平移 -δ；
- 同等幅度的干扰物位移；
- 仅背景/光照变化。

固定机器人状态、指令、策略噪声和推理设置。物体位移要保持可达性、无初始穿透及任务可解性。最初选择尚未接触目标的阶段，避免把不连续接触动力学混入微小扰动解释。

主诊断先用机器人基坐标中的小幅平移，之后再测试未见方向、幅度、组合以及其他阶段。不要开始就宣称任意 SE(3) 或复杂接触条件下普适。

仿真真值可以用于生成扰动和评价，不能作为部署策略的额外输入。干扰物、目标、相机变化要分别统计，不混成一种 OOD。

### 5.2 测量物理响应，而不只测 latent 距离

设 o+、o- 是正负扰动后的观测，使用相同策略噪声 ξ。令 u 是经过实际动作归一化和控制接口转换后的、可比较的短时末端运动量：

```
R_pi(delta) = [u_pi(o+, q, instruction; xi)
               - u_pi(o-, q, instruction; xi)] / (2 * delta)
```

这是沿一个物理方向的有限差分响应，不是完整 Jacobian，也不是稳定性证明。

最初用自由空间接近阶段的任务误差定义正确响应。对推、放置和接触阶段另设合理的局部目标；不能假定“物体右移，任何时刻都应该立刻向右动”。

完整指标包括：首次有效纠偏时间、纠偏方向、误差随时间的变化、超调/振荡、扰动后恢复率和最终成功率。

### 5.3 因果钳制：把候选内部通路的扰动响应关掉

在候选层提取同一快照下 h0、h+、h-，训练 SAE 得到 z0、z+、z-。对候选特征集 S，在受扰动分支中只把 S 的值替换为无扰动分支值：

```
h_clamp = h_perturbed + D_S (z_nominal,S - z_perturbed,S)
```

保留重建残差，避免把 SAE 重建失真误当作因果效应。该写回技巧已有工作，不声称原创。[3]

然后比较：钳制是否损害纠偏；同规模随机特征是否同样损害；是否只是任何动作都被破坏；换成干扰物扰动是否也得到相同效应。

无扰动分支在这里是**离线诊断的反事实参照**，不允许拿它作为部署时可访问的信息。

单个位置钳制只能说明该位置/特征集合的干预效应。若要声称一条“通路”，还应完成上游、下游的组合干预、阻断和恢复测试，不能用几张热图命名完整 circuit。

### 5.4 必要性与可恢复性必须分开

在本来能纠偏的样本上，钳制后纠偏下降，可支持该组计算对这些样本的必要性。

在本来不能纠偏的样本上，后续定向修复使纠偏恢复，提供另一类证据。不能用“在健康样本上消融会失败”直接推出“所有失败都由该特征导致”。

尤其不能只给失败样本注入正确动作方向，再宣布找到了原模型的纠偏机制。训练出的新通道可能是新增能力；需要明确区分**恢复既有通路**与**学习一条补偿通路**。后者仍可能有价值，但结论要相应改变。

## 6. 方法：根据反馈定位结果做局部修复

### 6.1 基础模型与采集位置

使用有可靠任务适配 checkpoint 的 π0 或 π0.5，先复现闭环基线。第二模型选择有成熟评测环境的不同架构，验证不是单一实现的偶然现象。

检查 VLM 的视觉/融合位置、动作专家中间位置和二者的信息传递位置。先做少量层的粗定位，再训练局部 SAE。不要先固定 layer 10，也不要假定 VLM 与 action expert 都是 1024 维。

保留逐 token、逐去噪时间、逐控制时刻信息；去噪时间和真实机器人时间是不同变量。以往整条轨迹平均后的特征不适合本项目主分析。

### 6.2 反馈作用驱动的特征选择

在训练/验证任务上选择一个小特征集合，使其钳制对纠偏影响明显、对名义执行影响较小，同时排除只响应背景变化的特征。

选择过程使用：反馈损失、正常任务损失、干预范数和集合大小。做组合集合与单特征对照，检查冗余与非加性，不把单特征分数相加当作通路效果。

锁定选择规则后，去未参与定位的任务评估。每个测试任务重新挑特征会破坏“跨任务反馈接口”的主张。

### 6.3 可实施的第一版修复结构

在选定位置增加小型残差适配器，或者只在对应模块训练低秩更新。基础版本可写为：

```
h_repaired = h + D_S * f_phi(z_S, c)
```

其中 z_S 来自当前真实观测下的内部表示，c 只包含该策略部署时已有的指令/本体状态上下文。D_S 可以固定，f_phi 使用小型网络并零初始化。

部署时不输入扰动标签、无扰动反事实图像、正确动作或物体真值坐标；不存在一个外部 oracle 持续告诉机器人向哪纠偏。

若早期层有可靠状态信息、下游写入作用不足，可让小适配器连接已经因果验证的上游与下游。此时必须增加“相同参数量、未经因果选择的普通跨层适配器”基线，避免将普通 skip connection 的收益归因于解释方法。

这一适配器结构本身不是主要创新。主要创新是物理反馈作用的因果识别，以及据此修复能带来可验证的选择性与迁移优势。

### 6.4 训练监督与损失

收集少量配对扰动后的正确恢复示范。可用可靠脚本专家或人工纠偏；所有基线共享这些数据。

最小目标：

```
L = L_recovery + lambda_keep * L_nominal
    + lambda_response * L_response
    + lambda_nuisance * L_nuisance
```

- L_recovery：扰动状态下正确恢复动作的监督。
- L_nominal：保持无扰动任务能力；不能只用 nominal 动作误差，还要做闭环检验。
- L_response：匹配配对扰动带来的正确动作变化。
- L_nuisance：对确实不改变所需动作的外观变化保持输出一致。

**差分/导数匹配并非新发明，TaSIL 已有直接相关思想。**[9] 本项目必须证明因果定位带来的价值，不能把上式重新命名就当新算法。

对 flow-matching 策略，动作监督沿用真实动作的 flow-matching 目标。响应约束优先在同噪声下完成采样后的短时动作上定义；若用单次速度预测近似以节省计算，应明确它只是代理，并验证它与最终物理纠偏的一致性。

不同专家轨迹可能有不同有效动作；专家监督需匹配阶段和初态。不能让随机轨迹风格差异充当“反馈响应”。

## 7. 需要交付的论文证据

### 7.1 主图应该是什么

第一张图应展示同一个外部扰动下的三条链：

```
物体位置变化 → 内部状态变化 → 纠偏动作 → 任务恢复
```

分别呈现正常策略、反馈失效样本和修复策略，并附真实运动轨迹。用它解释“输入已更新”和“输出正确响应”之间的差别。

核心因果图展示：钳制选中特征、随机特征、名义执行特征，对正常成功率和扰动恢复率产生何种不同影响。

不把 t-SNE 放在主证据位置。

### 7.2 主评测矩阵

| 维度 | 最低合理覆盖 |
|---|---|
| 任务 | 接近/抓取、搬运后的放置对准、推物体等具有不同误差定义的任务 |
| 扰动 | 目标位移、机器人初始偏差、目标与干扰物组合变化 |
| 对照扰动 | 干扰物移动、背景/光照变化 |
| 泛化 | 未见任务、未见扰动方向/幅度、未见布局 |
| 模型 | π0 系列主模型，加一个不同架构验证主要结论 |
| 时序 | 仿真暂停推理的机制实验，以及真实延迟下的部署实验分别报告 |
| 硬件 | 实物受控扰动与匹配基线，而非精选成功视频 |

先完成小范围可信结果，再扩展任务覆盖。动态扰动后的任务必须仍然可完成；失败案例要区分不可达、感知错误、动作延迟和反馈映射错误。

### 7.3 必须击败或解释的基线

1. 原始策略，普通 horizon 与单步重新规划均测试。
2. 同数据、同训练预算的全局 LoRA/恢复示范微调。
3. 仅加响应匹配损失的训练：检验因果定位是否必要。
4. 同参数量随机位置、激活强度选择、失败相关性选择的适配器。
5. 相同维度的 PCA、稠密子空间和 SAE；不预设 SAE 最优。
6. SOUL 或条件匹配的特征修复实现，明确它与本任务设定的差异。[4]
7. 至少一个观测更新/动态调度强基线，以及“调度方法 + 本方法”。[6–8]
8. 普通视觉伺服/输出残差控制基线，确保“内部修复”不是比外部简单控制更复杂却无收益。

CTRL-STEER 是需要审计的直接相关工作；若其控制目标与本任务不同，不能直接拿原文分数比较。应在共同可定义的目标上做匹配实现或限定结论。[5]

统一相机、动作接口、数据权限、控制频率和新增计算成本。专家纠偏数据也计入预算。按任务与场景分层统计，报告多训练种子与配对置信区间。

## 8. 实物验证如何支撑核心贡献

实物首先选一个容易精确重置和量化位移的设置：在抓取接近阶段，目标沿标定方向移动；在放置阶段，容器改变位置。扰动可以由可控移动平台实现，或通过有记录、可重复的操作实现。

位置测量或标记系统可用于评价，但不得只给本方法提供额外状态。记录画面采集时间、推理起止、动作入队及执行时间，防止把通信延迟伪装成内部反馈问题。

重点报告：

- 新画面到达后多久开始正确纠偏；
- 末端到目标的误差是否实际缩小；
- 是否出现过冲、抖动或对干扰物错误响应；
- 扰动后恢复率，以及无扰动性能保留；
- 未参与训练的物体/布局上是否仍有效。

不需要为论文故意制造高风险接触；从可控的小幅位移建立机制证据，之后再扩展到接触变化。新方法不自动具有稳定性或安全保证。

## 9. 为什么它比上一方案更值得押注

上一方案围绕目标语义交换，直接挨着 SAE steering、目标通路分析与 IIT，容易被认为是成熟工具组合。

这个方案有一个不同的科学对象：**基础策略的闭环反馈计算如何工作、在哪失效、能否被选择性修复。**

它可以形成三项紧密相连的贡献：

1. 在控制延迟与感知条件后，识别一类内部反馈失效，而不是笼统报告 OOD 掉点。
2. 用物理扰动和内部钳制建立反馈特异性的因果证据，使 latent 具有控制含义。
3. 根据机制进行少量参数修复，并展示跨任务、跨扰动、真实硬件上的恢复收益。

这是我现在愿意推荐的研究主线。其价值来自解释与改善同一个机器人问题，不依赖发明一个新缩写。

**需要主动防范的两条审稿意见：**

- “这就是 TaSIL 或数据增强”：用同样响应损失、同样恢复数据的基线，验证因果选择的额外作用。
- “这就是 SOUL 或动态 steering”：证明修复的是带方向的扰动—纠偏映射，而非永久压低失败特征或在线调整预设概念强度。

如果只有一个小适配器提高成功率，而找不到选择性反馈证据，那就不能按这篇机制论文的定位投稿。

## 10. 前四周推进计划

**第 1 周：建立能区分原因的评测。** 复现任务适配 π0 闭环；实现仿真快照分叉与正负位移；逐步重新推理，确保最新画面进入模型；记录响应轨迹。第一件事是实验基础设施，不是先训练大字典。

**第 2 周：做局部因果定位。** 选少数成功和失败场景，检查位置可读出性；对少量候选层进行钳制及随机对照；区分感知失败和动作响应失败。位置 probe 只是筛查，不作为结论。

**第 3 周：建立反馈特征集合与修复原型。** 训练小规模 SAE 与稠密基线，筛选反馈特异性位置；准备统一的恢复示范；实现零初始化局部适配器。

**第 4 周：进行首轮公平比较。** 比较原始模型、恢复数据 LoRA、仅响应匹配、随机位置修复、因果位置修复。以未见场景的闭环恢复率决定是否进入大规模实验。

在 5090 服务器上先测一次实际吞吐，再确定 SAE 宽度、训练 batch 与 rollout 并行数。以上是研究任务顺序，不是未经测量的工期保证。

若第一阶段表明单步新观测重规划已经解决全部目标失败，或者状态变化根本没被编码，就明确否定该设置中的反馈失效假设，不继续把调度/感知问题包装成通路发现。

## 11. 面向 CoRL 2027 的完成标准

有竞争力的完成形态应是：明确机制、严谨反事实对照、作用可迁移的局部修复、强基线，以及与机制一致的实物结果。

不设置虚假的“提高多少点就必中”标准。目标是同时回答：为什么失败、改变哪里有用、为什么这比普通训练更有效、能否在新的任务中仍然成立。

建议 2026 年底前完成机制与主方法，2027 年初完成主仿真和第二模型，之后完成实物、消融与论文。正式截止日期须以 CoRL 2027 官方通知为准。

论文标题中的“Seeing”只是便于表达；正式结论应写成“可从内部表示读出状态变化”，避免将探针结果等同于模型已经理解现实。
